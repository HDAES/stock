# AGENTS.md

This repository is a small Python 3.11 quant research package for US equities. It uses the Longbridge CLI for market data, caches raw responses locally, and runs a first-pass multi-factor S&P 500 rotation workflow from cached data.

## Project Shape

- `src/stock_quant/`: package code.
- `src/stock_quant/cli.py`: `stock-quant` entry point and subcommands.
- `src/stock_quant/longbridge.py`: thin wrapper around the external `longbridge` CLI.
- `src/stock_quant/cache.py`: local JSON cache plus kline normalization.
- `src/stock_quant/factors.py`: momentum, value, quality, low-volatility factors and score table.
- `src/stock_quant/strategy.py`: top-N selection, equal weights, and SPY moving-average exposure filter.
- `src/stock_quant/backtest.py`: simple weighted return series and performance metrics.
- `src/stock_quant/analysis.py`: shared analysis service functions used by CLI and Web API.
- `src/stock_quant/web/`: FastAPI application and response schemas.
- `frontend/`: Vite/React/TypeScript web application.
- `config/default.json`: default universe, factor weights, data paths, and strategy parameters.
- `tests/`: focused pytest coverage for calculation behavior.
- `data/` and `reports/`: generated local artifacts, ignored by git.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
longbridge auth login
```

The package requires `numpy` and `pandas`; development tests require `pytest`.

## Common Commands

Run tests:

```bash
pytest
```

Check Longbridge CLI access:

```bash
longbridge quote TSLA.US --format json
```

Fetch and cache daily bars:

```bash
stock-quant fetch --symbols AAPL.US MSFT.US NVDA.US SPY.US --count 500
```

Refresh cached data when stale:

```bash
stock-quant fetch --symbols AAPL.US MSFT.US NVDA.US SPY.US --count 500 --refresh
```

Rank cached universe:

```bash
stock-quant rank --config config/default.json
```

Run the current cached-data backtest:

```bash
stock-quant backtest --config config/default.json
```

Start the API server:

```bash
uvicorn stock_quant.web.api:app --reload
```

Start the React app:

```bash
npm install
npm run dev
```

Build the React app:

```bash
npm run build
```

## Data And Runtime Notes

- Do not commit `data/`, `reports/`, virtualenvs, pytest caches, or generated bytecode.
- `DataCache` creates `kline/` and `calc_index/` directories under the configured cache directory.
- Cached Longbridge payloads are stored as JSON. Prefer preserving raw payloads and normalizing at read time.
- Symbols use Longbridge suffixes such as `AAPL.US` and are converted to filenames by replacing `.` with `_`.
- `load_config()` resolves `data.cache_dir` relative to the config file parent, so `config/default.json` points to the repository-level `data/cache`.
- The project is research-only. Do not add live order placement without a separate explicit design and strong safety gates.

## Coding Guidelines

- Follow the existing simple functional style. Add small functions near the domain they serve before introducing broader abstractions.
- Keep public CLI behavior stable unless the task explicitly asks to change it.
- Use pandas/numpy operations for calculations rather than ad hoc loops when the intent is vectorized series work.
- Keep factor calculations deterministic and testable with in-memory pandas objects.
- Handle missing or malformed vendor data defensively. Existing code treats absent factor inputs as `NaN` and fills normalized score contributions with `0.0`.
- Keep Longbridge integration isolated in `longbridge.py` and cache behavior isolated in `cache.py`.
- Avoid network-dependent tests. Unit tests should not require Longbridge credentials or live market access.
- Keep Web API endpoints cache-first unless the endpoint is explicitly a refresh action.
- Keep frontend build outputs and dependencies out of git: `frontend/dist/` and `frontend/node_modules/` are ignored.

## Current Strategy Assumptions

- Universe: configured US symbols, initially a liquid large-cap list.
- Benchmark/risk filter: `SPY.US`.
- Factors: 60-day momentum, value, quality, and inverse 60-day annualized volatility.
- Ranking: z-score each factor cross-sectionally, apply configured weights, sort descending.
- Selection: top `strategy.top_n` symbols.
- Exposure: full exposure when SPY is above its 200-day moving average, otherwise defensive exposure.
- Portfolio: equal-weight selected symbols at the selected exposure.
- Backtest: current implementation computes returns over the cached window using current target weights; it is not yet a true historical monthly rebalance simulation.
- `transaction_cost_bps` exists in config and `apply_turnover_cost()` exists, but the CLI backtest does not currently apply turnover costs.

## Testing Expectations

- Add or update pytest tests when changing factor math, strategy selection, cache normalization, or performance metrics.
- Keep tests focused and deterministic.
- For code that touches Longbridge subprocess behavior, prefer injecting a fake client or mocking subprocess output.
- Before handing off code changes, run:

```bash
pytest
```
